Bearly Chat demo

A practice walkthrough. Nothing you do here is saved or requests your location.

Having trouble installing? Open https://tmpark12.github.io/Bearly-Chat/ in a browser, then select Install app.

1. Pick a feeling

😊 Happy😢 Sad😠 Mad

Ask the child to choose a face that matches how they feel. In the popup, choose Yes to confirm or No to choose another face. After confirming, choose whether to add another feeling, up to three different feelings. Choose No to continue to colors.

Use Hear the question to play the question again when a device voice is available.

2. Pick a color

RedBlueYellow

Choose any color that feels right. In the popup, choose Yes to continue or No to choose another color.

Select Back to feelings to choose the feelings again.

3. Add notes or skip

The device owner may add optional notes, or choose Skip notes and continue. Choose Back to colors to change the color.

Notes are included in saved check-ins and CSV exports.

When Do Not Save is on, the notes page is skipped.

4. Save the check-in

To save, turn off Do Not Save in Settings. Location is optional. Choose Cancel to return without saving.

When Do Not Save is on, choose Done without saving. When it is off, choose Save check-in. If location is enabled, permission and a location fix are required.

If multiple users are enabled, select a user in Settings before saving.

5. Download or review

Only saved check-ins can be downloaded. Opening a saved map link shares its coordinates with Google Maps.

Use Saved check-ins to review or export records. Verify downloads before clearing records. Exports can contain location and device information; keep them private. Records do not sync.

Settings demo

This guide explains each Settings area without changing your settings.

For a copy to keep, choose “Save as PDF” in your device's print options, if available.

Voice

Turn Read questions aloud on or off. Adjust speech rate and volume with the sliders, choose a voice and language, or check Mute speech. Use Hear voice to preview the voice.

Voices depend on your device and may be unavailable or require a connection.

Check-in

Check Randomize to shuffle choices. Do Not Save is on by default: new check-ins are not saved, the notes page is skipped, and location is not requested. Uncheck it to save check-ins.

Save location with check-ins is off by default. Check it to request location when saving; permission and a location fix are then required.

Save for multiple users

Check Save for multiple users to enable profiles. Choose Add user and enter a non-identifying nickname, then select the current user before saving or viewing their records. Turn it off to view older unassigned records.

User names stay on this device even when Do Not Save is on; profiles are not password-protected. Export creates a user folder where supported, or downloads a named CSV.

Display

Check Larger text, High-contrast mode, or Reduce motion to make the app more comfortable to use.

Saved data

Choose Export check-ins (CSV) to review and export saved records. Verify the exported file before clearing data. Clear saved check-ins removes saved records for all users, including the old backup.

Delete downloaded files separately. Show demo invitation again restores the invitation for the next installed launch; Help and demo opens the main walkthrough.

Privacy

Choose Read the privacy policy to learn what is stored, how to delete it, and how to keep exports private.
